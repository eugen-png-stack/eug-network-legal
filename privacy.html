Privacy Policy / Datenschutzerklärung

Last updated: 13 October 2026 · Diese Anwendungen werden ausschließlich privat von der Person genutzt, die das Google-Konto verbindet.

1. Scope

This policy covers the private automation applications operated under eug.network (including the client registered in the Google Cloud console as "Hermes Email"; together, the "Applications"). Each Application is a single-user client used only by the owner of the Google account that authorises it. It is not a public service, it has no other users, and it is not licensed or distributed to third parties.

2. Google data the Applications access

  • Gmail (gmail.readonly, gmail.modify, gmail.compose) — to list and read messages, to label or move them, and to create drafts or send messages strictly on the owner's instruction.
  • Google Drive (drive, drive.readonly, drive.metadata.readonly) — to locate, read and manage files the owner asks about.
  • Google Calendar (calendar.readonly, calendar.events, calendar.calendarlist.readonly) — to read calendars and events and to create or update events on the owner's instruction.

No other Google data is requested. Access tokens are limited to the scopes shown on the consent screen.

3. Where data is processed and stored

All processing happens on a private server controlled by the account owner. OAuth tokens and message metadata are stored only on that server, protected by restrictive file permissions and SSH key authentication. Content is processed locally; it is never uploaded to third-party analytics, advertising or profiling services.

4. Sharing and limited use

Data is not sold, rented, published or shared with third parties, and is not used for advertising or profiling. The Applications' use of Google user data is limited to the practices described in this policy, in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

5. Retention and deletion

Content is kept only as long as needed for the task requested by the owner. Access can be revoked at any time at myaccount.google.com/permissions; stored tokens are deleted on request or when access is revoked.

6. Security

Transport to Google APIs uses TLS. Server access requires SSH key authentication and credentials are stored with restrictive permissions.

7. Contact

Questions or deletion requests: contact@eug.network

The Applications are not directed to children and are not intended for public use.
